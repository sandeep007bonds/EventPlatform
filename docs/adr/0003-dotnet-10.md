# ADR-0003 — Language/runtime: .NET 10 (LTS)

- **Status:** Accepted
- **Date:** 2026-07-23

## Context

Backend services are .NET. The choice was between .NET 8 (LTS) and .NET 10
(LTS, released November 2025).

## Decision

Standardize on **.NET 10 (LTS)** for all services. C# is the primary language;
Minimal APIs for the lean hot-path services, full ASP.NET Core for the rest.

## Consequences

- Three-year LTS support window, latest performance and tooling (.NET Aspire and
  Container Apps/AKS integration target .NET 10 best).
- A consistent runtime across all services simplifies the shared building-blocks
  and the service template.
- Go remains an *option* for an ultra-hot path only if profiling proves .NET
  insufficient — not adopted pre-emptively.

## Alternatives considered

- **.NET 8** — also LTS but older; no reason to start greenfield on it.
- **Polyglot from day one** — rejected; premature fragmentation.
